BOOKVERSE

An Immersive 3D Interactive Digital Library & Distributed Social Reading Platform

✦ Abstract

BookVerse is an end-to-end full-stack literary ecosystem designed for bibliophiles, scholars, and avid readers. It unifies high-performance relational database management with modern web engineering to transform static book catalogs into an immersive literary experience.

Powered by a decoupled FastAPI (ASGI) asynchronous REST backend, an optimized MySQL 8.0 (InnoDB) database, and a reactive React 18 + Vite client featuring 3D skeuomorphic scroll-turn canvas physics with realistic desk stationery.

✓ Key Outcome: Eliminates catalog latency, guarantees complete relational integrity with cascading schemas, and provides a tactile, distraction-free reading portal.

✦ Problem & Objectives

The Problem: Conventional book platforms (e.g., legacy Goodreads) suffer from outdated interfaces, sluggish monolithic API queries, intrusive advertisements, detached shelving tracking, and lifeless metadata grids lacking visceral connection to literature.

  • Obj 1: Relational Scalability: Engineer a 3NF normalized MySQL database with foreign-key integrity constraints for 58+ classic and contemporary volumes.
  • Obj 2: High-Throughput REST Gateway: Build an asynchronous Python FastAPI service offering sub-35ms CRUD endpoints, schema validation via Pydantic v2, and multi-part asset streaming.
  • Obj 3: 3D Skeuomorphic Experience: Create an interactive open-tome scroll canvas with dynamic forward/backward leaf flippers, authentic classic manuscripts, and realistic HB pencils.
  • Obj 4: Shelf & Social Lifecycle: Provide real-time reading progress sliders, multi-tier shelf status, and community critique boards.

✦ Project Scope

Users: General readers, academic literature researchers, book clubs, and system administrators.
Modules: Catalog Explorer, Dynamic Shelves (Want / Reading / Completed), Voices & Critique, Reading Velocity Streaks, AI Literary Oracle, and Local Image Asset Pipeline.

The decoupled 3-tier architecture isolates UI state from relational storage, preventing database locks and enabling stateless horizontal API scaling.

✦ ER Diagram & Relational Design

USERS
PK user_id VARCHAR(36) username VARCHAR(50) [UQ] email VARCHAR(255) [UQ] password_hash VARCHAR(255) created_at DATETIME
BOOKS
PK book_id VARCHAR(36) title VARCHAR(255) [IDX] author VARCHAR(255) isbn VARCHAR(20) [UQ] price DECIMAL(10,2) cover_image_url VARCHAR(255)
REVIEWS
PK review_id VARCHAR(36) FK user_id (USERS.user_id) FK book_id (BOOKS.book_id) rating INT CHECK (1..5) review_text TEXT
READING_LIST
PK list_id VARCHAR(36) FK user_id (USERS.user_id) FK book_id (BOOKS.book_id) status ENUM('want', 'reading', 'completed') added_at DATETIME

Integrity Rules: Referential integrity enforced via ON DELETE CASCADE. Normalized in 3NF to eliminate update and deletion anomalies.
